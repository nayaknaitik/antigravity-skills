# Typography & Grid Specification

## Typography
- **Primary Font**: `Poppins` (Weights: 400, 500, 600).
- **Fallback Stack**: `ui-sans-serif, system-ui, sans-serif`.
- **Numbers/Data**: ALWAYS apply `tabular-nums` CSS class/property to tables, P&L, and prices.

## Spacing Grid
- Follow a strict 4px/8px baseline grid.
- **Micro-spacing**: `space-x-1`, `gap-2` for dense data grids.
- **Macro-spacing**: `p-4`, `p-6` for card padding, `space-y-6` for dashboard sections.
- **Borders**: 1px borders (`border-slate-200`) rather than heavy drop shadows to define elevation.
