# Code Review Skill - Maintainer Guide

1. **References**: Update `references/` when new security benchmarks (OWASP Top 10) or language standards update.
2. **Review Engine**: Enhance `scripts/code_review_engine.py` regex rules for language-specific anti-patterns.
3. **SemVer**: Maintain Semantic Versioning 2.0.0 in `metadata/skill.json`.
