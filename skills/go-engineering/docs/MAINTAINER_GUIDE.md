# Go Engineering Skill - Maintainer Guide

## Updating the Skill
1. **References**: Update `references/` when new Go toolchain versions (e.g. Go 1.23+) release.
2. **Linter Maintenance**: Synchronize `scripts/go_code_linter.py` with new Go Proverbs or style updates.
3. **SemVer**: Maintain Semantic Versioning 2.0.0 in `metadata/skill.json`.
