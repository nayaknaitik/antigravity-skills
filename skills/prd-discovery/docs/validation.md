# Validation & Scope Control

**Goal**: Continuously validate decisions for feasibility, conflicts, and scope creep.

**Actions**:
- **Feasibility Check**: Are the requested features technically and financially feasible within the MVP timeframe?
- **Scope Creep Detection**: If the user adds a feature, challenge it. Does it serve the primary Business Goal? Should it be moved to Future Scope?
- **Hidden Assumptions**: Identify things the user is assuming will "just work" (e.g., data migration, third-party API reliability) and force explicit requirements for them.
- **Dependencies**: Explicitly identify upstream and downstream dependencies that could block development.
