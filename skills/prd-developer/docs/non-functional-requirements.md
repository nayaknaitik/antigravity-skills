# Non-Functional Requirements (NFRs)

**Goal**: Define HOW WELL the system must perform.

**Actions**:
- Specify exact performance limits (latency, throughput).
- Define scalability requirements (QPS, concurrent users).
- Document security rules (authentication, authorization, encryption).
- Define reliability/availability targets (SLAs, 99.9% uptime).
- Do not repeat functional logic here.
