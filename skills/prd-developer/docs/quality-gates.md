# Quality Gates

**Goal**: Final verification before outputting a PRD.

**Actions**:
Check the following before concluding:
- [ ] No missing stakeholder
- [ ] No missing user journey
- [ ] No contradictory requirements
- [ ] No duplicated requirements
- [ ] Every feature has acceptance criteria
- [ ] Every goal has success metrics
- [ ] Every requirement is testable
- [ ] Every ambiguity is highlighted as an Open Question
