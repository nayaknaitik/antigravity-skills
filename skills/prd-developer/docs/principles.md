# Principles

1. **Outcome over Output**: Focus on the problem being solved, not just features.
2. **Clarity**: Eliminate ambiguity. Separate facts from assumptions.
3. **Traceability**: Every feature must map to a goal and a user pain point.
4. **Testability**: Every requirement must be measurable and testable.
5. **Efficiency**: Ask only high-value, high-leverage questions to resolve ambiguity.
